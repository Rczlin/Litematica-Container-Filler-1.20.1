一个 Litematica 辅助模组，一键填充投影容器

### 功能
* **智能装填**：自动从背包或快捷潜影盒中提取材料并填入投影中缺失物品的容器
* **模式切换**：准星和范围，按住和持续填充模式，类似投影打印机

### 运行依赖
* **Minecraft**
* **Fabric API**, **MaLiLib**, **Litematica**
